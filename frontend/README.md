# Web2Mag — Frontend Module

This directory contains the React 19 + Vite frontend application for **Web2Mag**.

See the root [`../README.md`](../README.md) for full project architecture, running instructions, and backend specifications.

### Scripts
```bash
# Start Vite development server
npm run dev

# Run ESLint
npm run lint

# Production build
npm run build

# Preview build
npm run preview
```
